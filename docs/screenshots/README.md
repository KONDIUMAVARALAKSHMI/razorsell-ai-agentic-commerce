# Screenshots

No static screenshots are checked into this repository — they'd go stale the
moment the UI changes, and a reviewer can have the real thing running in
about five minutes (see the root README's "Setup instructions").

If you're packaging this project for a submission that requires images,
drop them here with descriptive names, e.g.:

- `01-customer-chat.png`
- `02-product-recommendations.png`
- `03-cart-and-checkout-confirm.png`
- `04-payment-failure-recovery.png`
- `05-merchant-overview.png`
- `06-audit-trail.png`
- `07-failure-center.png`

and reference them from the root `README.md` §9.
